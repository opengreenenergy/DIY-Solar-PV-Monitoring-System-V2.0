# DIY Solar PV Monitoring System V2.0

A compact and powerful solar monitoring system designed to measure important photovoltaic parameters such as voltage, current, power, energy, and temperature.

The system is based on the **Seeed XIAO ESP32** microcontroller and allows both **local monitoring through an OLED display** and **remote monitoring through the Blynk mobile application**.

This project helps solar system owners understand the performance of their solar panels and detect issues early.

## Key Features

• Solar panel voltage measurement  
• Solar current measurement using Hall current sensor  
• Power and energy calculation  
• Solar panel temperature monitoring  
• Local OLED display for real-time data  
• Remote monitoring using Blynk mobile dashboard  
• WiFi enabled ESP32 platform

---

## Hardware Used

• Seeed XIAO ESP32 microcontroller  
• ACS758 Hall current sensor  
• ADS1115 16-bit ADC  
• DS18B20 temperature sensor  
• OLED display (SSD1306)

## Measured Parameters
